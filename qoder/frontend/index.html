ResearchFlow - 科研文献智能检索助手

🎯 解决的问题

科研工作者日常需要管理大量文献，传统关键词搜索难以理解语义，纯向量搜索又无法精确匹配专业术语。ResearchFlow 基于 seekdb 的混合检索能力，将向量语义搜索、全文关键词搜索和结构化条件过滤统一在一条查询中，帮助研究者快速定位相关文献段落。

⚙️ 核心功能

  • 混合检索：一条查询同时执行向量相似度搜索 + BM25 全文匹配 + 结构化过滤（年份、标签、作者）
  • 文献管理：导入、浏览、编辑、删除文献记录，支持阅读状态追踪
  • 语义理解：支持自然语言查询，理解搜索意图而非仅匹配关键词
  • 数据看板：可视化展示文献库统计信息

💾 技术架构

  • seekdb：AI 原生搜索数据库，提供向量索引（HNSW/IVF）、全文索引（IK 分析器）和关系存储
  • 后端：Python Flask REST API + pyseekdb SDK
  • 前端：原生 HTML/CSS/JavaScript 单页应用
  • 部署：seekdb 嵌入式模式（.db 文件）或 Docker/Server 模式
