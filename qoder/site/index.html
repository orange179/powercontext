ResearchFlow

科研文献智能检索助手

基于 seekdb 混合检索能力，将向量语义搜索、全文关键词匹配和结构化条件过滤统一在一条查询中，帮助科研工作者快速定位相关文献。

解决的问题

🔍

语义理解不足

传统关键词搜索无法理解「向量检索」和「近似最近邻搜索」是相关概念，遗漏重要文献。

💬

精确匹配缺失

纯向量搜索无法精确匹配专业术语、模型名称和数据集引用，检索结果不够精准。

🔀

多工具切换

需要同时使用向量数据库、全文搜索引擎和关系数据库，增加系统复杂度和运维成本。

核心功能

🧠

混合检索

一条 SQL 同时执行向量相似度搜索 + BM25 全文匹配 + 结构化过滤（年份、标签、作者），无需多次查询和结果融合。

seekdb HNSW IK Analyzer
📄

文献管理

导入、浏览、编辑、删除文献记录，支持阅读状态追踪（未读/在读/已读），按标签和年份分类管理。

CRUD Metadata
📊

数据看板

可视化展示文献库统计信息：文献总数、标签分布、年份分布、阅读进度，一目了然掌握研究进展。

Statistics Visualization
⚡

嵌入式部署

seekdb 嵌入式模式，单个 .db 文件即可运行，无需额外服务。支持远程服务器模式和模拟模式，跨平台兼容。

混合检索 SQL 示例

SELECT id, title,
    l2_distance(embedding, '<query_vector>') AS vec_score,
    MATCH(title, abstract, content) AGAINST('vector search') AS text_score
FROM research_papers
WHERE MATCH(title, abstract, content) AGAINST('vector search')
    AND year >= 2024
    AND tags LIKE '%database%'
ORDER BY (0.6 * vec_score + 0.4 * text_score) DESC APPROXIMATE
LIMIT 10;

快速开始

1

克隆项目

git clone https://github.com/oceanbase/powercontext.git
cd powercontext/qoder
2

安装依赖

pip install -r requirements.txt

需要 Python 3.11+，依赖：flask, flask-cors, pyseekdb, pymysql

3

配置环境变量（可选）

cp .env.example .env
# 编辑 .env 设置 SEEKDB_MODE=auto|embedded|remote|simulated

默认 auto 模式：自动检测平台并选择最佳连接方式

4

启动应用

cd backend
python app.py

启动成功后访问 http://localhost:5000

5

导入示例数据

打开浏览器，进入「文献管理」标签页，点击「导入示例数据」按钮，系统将导入 10 篇示例论文。
